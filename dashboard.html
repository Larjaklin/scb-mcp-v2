Demografisk utveckling

Västra Götaland och Sverige står inför en demografisk omvandling med sjunkande barnafödande, åldrande befolkning och regionala obalanser. Över hälften av länets kommuner minskar i folkmängd.

⚡ Snabbguide: Hämta data från SCB PxWeb API

Exempel på hur man anropar SCB:s öppna API direkt i JavaScript
// Hämta fruktsamhetstal för Sverige från SCB PxWeb API
const url = "https://api.scb.se/OV0104/v1/doris/sv/ssd/START/BE/BE0701/BE0701A/SumFruktsamhetK";

const query = {
  "query": [
    { "code": "Region", "selection": { "filter": "vs:RegionLan", "values": ["14"] } },
    { "code": "Tid",    "selection": { "filter": "item",         "values": ["2020","2021","2022","2023"] } }
  ],
  "response": { "format": "json" }
};

const response = await fetch(url, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(query)
});
const data = await response.json();
// data.data[] innehåller värdena per år
console.log(data.data.map(d => ({ år: d.key[1], värde: d.values[0] })));
